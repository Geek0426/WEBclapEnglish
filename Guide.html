Web Clap (Again)

English edition 1.0.0 · October 30, 2026

Receive anonymous claps and optional messages, customize thank-you pages, and publish replies from one admin area.

Requirements and tested environments

PHP 8.3 or later, HTTPS, Fileinfo, and writable file storage with file locking are required. No database setup is needed. This release targets Apache-compatible servers that enforce the bundled .htaccess access restrictions. Email notifications require OpenSSL and SMTP. PHP cURL is required for certain hosting setups where the public and internal addresses differ.

The first-time environment check must pass before setup. Hosts that do not run PHP or ignore the access restrictions cannot use this package as-is.

The Japanese edition was tested by the creator on Sakura Rental Server in October 2026: setup, claps, messages, email delivery, images, replies and custom pages. This is not a guarantee for all Sakura plans. Other providers, PHP 8.3/8.4 execution, actual mobile devices, and installation through the WordPress editor have not been verified. Automated local tests use PHP 8.5.7. The English edition is additionally tested locally; it has not been deployed to a live host.

1. Install

  1. Extract the ZIP. It contains this guide and the webclap-sai app folder.
  2. Upload that folder into a new, empty location on your site using FTP or your hosting file manager. Include hidden .htaccess files. Do not overwrite an existing app.
  3. Open the installation URL followed by /public/index.php over HTTPS.
  4. Select Check server environment, then choose and save an admin password. Keep it safe.
  5. Confirm the time zone before accepting claps. Your device zone is suggested. Daily totals and limits reset at midnight in the saved zone; travel does not change it automatically. The zone cannot be changed after claps have been received.

For an app installed at https://example.com/webclap-sai/:

  • Admin: https://example.com/webclap-sai/public/index.php
  • Thank-you page: https://example.com/webclap-sai/public/clap.php
  • Public replies: https://example.com/webclap-sai/public/replies.php

Opening or reloading the thank-you page counts a clap, within the daily limit. Use the admin preview when you only want to check the design.

2. Add a clap button

Open the 36-button gallery and embed codes

Enter the path to your public folder in the gallery, for example /webclap-sai/public/. Copy a button code and paste it into your page HTML, such as at the end of a story. The images are included in the app upload.

For a text-only button:

<button type="button" data-webclap-button>Send a clap</button>
<script src="/webclap-sai/public/webclap-button.js" defer></script>

Replace the path with your own installation path. Include the script only once per page, even with multiple buttons. An image by itself does not send claps. Use the supplied button attributes and script.

The button and app must be on the same origin (scheme, host and port). Cross-domain embedding is not supported. A custom domain and a hosting provider domain are different origins. Opening in the same or a new tab follows your admin settings. When the thank-you page is OFF, the button records the clap without navigation and optionally shows the thank-you popup. Reaching the limit opens the limit page.

WordPress does not require a dedicated app plugin, but editor permissions or security settings may strip script tags. WordPress editor installation is not yet verified; the tested embedding scope is same-origin HTML pages.

3. Link to public replies

Publish replies in the admin area, then place a normal link in your site navigation:

<a href="/webclap-sai/public/replies.php">Clap replies</a>

For a new tab:

<a href="/webclap-sai/public/replies.php" target="_blank" rel="noopener noreferrer">Clap replies</a>

No clap script is needed for this link. Do not use the admin URL as your public replies link. Turning the replies page OFF hides it without deleting saved replies.

4. Admin area

Home: daily and monthly counts, a calendar and messages. A red dot marks new claps; a blue dot marks dates with messages. Opening a date clears its red dot. New claps can mark it again.

Select a message to write a reply. Generate the recipient line from any combination of date, name and opening words, then edit it freely. Only the recipient line and your reply are published, not the full received message. Replies are newest-publication first, with a default of ten per page. Editing, hiding and deleting are available. Hidden replies keep their Replied badge; deleting a reply clears it and keeps the original message.

Features: enable or disable features, open their settings, then select Save or Apply. Feature reset restores defaults without deleting messages, images, replies, passwords, email settings or your time zone.

The daily limit uses browser cookies, not strict person identification. Another browser or cleared cookies can bypass it. With a five-clap limit, the fifth clap and its message are accepted before the limit page appears; further claps and messages are blocked until midnight. Reloads count as claps, but duplicate message submissions are prevented.

Email: OFF by default. Enter one notification address and your SMTP details if wanted. Selecting connection security sets its standard port; advanced settings allow a different provider-specified port. The SMTP password is your email password, not the admin password. Notifications contain the name and full message, without a site link. The subject is Web Clap. Claps without messages do not send email. If email fails, the message is still stored; failed notifications are not automatically resent.

Design: choose Clap page or Replies page. Thank-you sets can contain an image, text, or both. All saved sets are randomly selected, with repeats allowed. At least one set must remain. The limit page has separate content. Replace the sample content before use.

Images support JPEG, PNG, GIF (including animation), and WebP, up to 10MB each or the lower server limit shown in the interface. Shared appearance offers background, automatic or manual text color and text size. Turning the send button OFF also hides the name and message fields.

Custom mode saves HTML and CSS per thank-you set. UTF-8 files up to 100KB each are supported. Use Choose and insert an image to register images. Insert message form places {{webclap_form}}; Insert replies list places {{webclap_replies}}. Custom pages do not load external scripts or files. Easy-mode content is kept. The public replies themes are Simple, Dark and Pastel, or your own Custom design.

5. Troubleshooting and password recovery

  • 404: check the uploaded folder and actual public URL. Hosting domains and custom domains can map to different folders.
  • Protection check fails: check .htaccess, write permissions, cURL support, TLS and server self-connections. Do not disable protection to bypass setup.
  • Missing images: check that the image folder was uploaded and the embed path is correct.
  • No email: check that notifications are ON and saved, verify SMTP details and spam folders. Read the saved message in the admin area.
  • Changes not visible: confirm saving completed, reload, and check any hosting or page cache.

If you forget the admin password:

  1. Using FTP or the hosting file manager, delete only Setting/auth/admin_auth.json.
  2. Immediately open the admin page, run the environment check and set a new password.
  3. Your stored content and settings remain. Do not delete the entire Setting folder.

While the authentication file is absent, only password setup is available; stored admin data cannot be viewed. Do not leave the reset unfinished.

6. Backup, updates and removal

Back up the entire app folder regularly. Setting contains passwords, email credentials, images and private messages: keep backups private. This ZIP is for a new installation. For future updates, back up first and follow the specific version instructions. Never replace an existing Setting folder with the empty distributed one. Direct migration from other CGI or PHP products is not included.

To remove the app, remove your site buttons, scripts and replies links, save any data you need, then delete only this app installation folder.
