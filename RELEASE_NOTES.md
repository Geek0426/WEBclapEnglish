# Web Clap (Again) 1.0.0 — English edition

The first public release. A PHP-based package for a new installation on your own website.

## Included

- Claps, optional anonymous messages, and a calendar with clap counts
- Thank-you images, text, random selection, and a thank-you popup
- Public replies and HTML/CSS customization
- Email notifications and time-zone settings
- 36 clap-button graphics with copyable embed code
- `Guide.html`

## Download and installation

Download **WEBclap-sai-1.0.0-en.zip** from **Assets** below.
After extracting the ZIP, open `Guide.html` first, then upload the `webclap-sai` folder into a new, empty location.
PHP 8.3 or later, HTTPS, the bundled `.htaccess` protection, and other documented requirements apply. Do not overwrite another app or an existing `Setting` folder.
